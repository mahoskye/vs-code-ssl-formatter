# Archive

Historical documents, kept for reference. They describe the extension or the
language as they were when written, and are **not** current.

| File | What it was |
| --- | --- |
| `ARCHITECTURE-original-spec.md` | The original design for an in-repo TypeScript language server and formatter. Neither exists now; the extension bundles starlims-lsp. See [../ARCHITECTURE.md](../ARCHITECTURE.md). |
| `feature-roadmap.md` | The Q3 2025 feature plan. |
| `CI_SETUP.md` | A November 2025 note on setting up CI. See [../../.github/workflows/README.md](../../.github/workflows/README.md). |
| `ssl-ebnf.md` | An early EBNF grammar for SSL. The maintained grammars (EBNF, tree-sitter, TextMate) are in [ssl-style-guide](https://github.com/mahoskye/ssl-style-guide). |
| `ssl-element-cheatsheet.txt` | A hand-kept list of SSL elements. |
| `sql-parameters.md`, `ssl-sqlexecute-parameter-substitution.md` | Notes on SQL placeholders in `SQLExecute` and `RunSQL`. |

For SSL language questions, use the
[SSL reference](https://github.com/mahoskye/starlims-ssl-reference), which is
verified on STARLIMS 12.
